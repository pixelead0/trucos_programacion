#### Estilo y Convenciones
- [PEP 8](https://peps.python.org/pep-0008/) - Style Guide for Python Code
- [PEP 20](https://peps.python.org/pep-0020/) - The Zen of Python
- [PEP 257](https://peps.python.org/pep-0257/) - Docstring Conventions

#### Type Hints y Anotaciones
- [PEP 484](https://peps.python.org/pep-0484/) - Type Hints
- [PEP 526](https://peps.python.org/pep-0526/) - Syntax for Variable Annotations
- [PEP 544](https://peps.python.org/pep-0544/) - Protocols: Structural subtyping

#### Funciones y Decoradores
- [PEP 3102](https://peps.python.org/pep-3102/) - Keyword-Only Arguments
- [PEP 318](https://peps.python.org/pep-0318/) - Decorators for Functions and Methods

#### Módulos y Paquetes
- [PEP 328](https://peps.python.org/pep-0328/) - Imports: Multi-Line and Absolute/Relative
- [PEP 420](https://peps.python.org/pep-0420/) - Implicit Namespace Packages

#### Context Managers y Generadores
- [PEP 343](https://peps.python.org/pep-0343/) - The "with" Statement
- [PEP 255](https://peps.python.org/pep-0255/) - Simple Generators
- [PEP 342](https://peps.python.org/pep-0342/) - Coroutines via Enhanced Generators

#### Entornos y Empaquetado
- [PEP 405](https://peps.python.org/pep-0405/) - Python Virtual Environments
- [PEP 517](https://peps.python.org/pep-0517/) - Build System
- [PEP 518](https://peps.python.org/pep-0518/) - Specifying Build System

#### Estructuras de Datos
- [PEP 428](https://peps.python.org/pep-0428/) - The pathlib module
- [PEP 557](https://peps.python.org/pep-0557/) - Data Classes
- [PEP 634](https://peps.python.org/pep-0634/) - Structural Pattern Matching

#### Manejo de Errores y Serialización
- [PEP 3134](https://peps.python.org/pep-3134/) - Exception Chaining
- [PEP 3154](https://peps.python.org/pep-3154/) - Pickle protocol
